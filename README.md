# Daily Works

个人每日规划 Web 应用：目标管理、习惯打卡、上班打卡、每日日志，附 AI 辅助。多用户各自独立，中英双语。

## 功能

- 目标：有期限 / 短期 / 长期三种类型，优先级、进度、里程碑、拖拽排序、每日贡献记录
- 习惯打卡：每日打卡、连续天数统计，徽章支持 8 种渐变样式
- 上班打卡：灵活上班时间、建议下班时间、加班统计与历史
- 每日日志：每天一条，附心情记录
- AI 辅助：自动生成目标描述、里程碑拆解与日志
- 界面：主题色与壁纸自定义；目标圆支持浅灰细格、磨砂玻璃或无覆盖三种未完成样式

## 运行

```
pip install -r requirements.txt
python run.py
```

打开 http://127.0.0.1:8665 ，注册账号即可使用。
